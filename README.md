# 养生价目表前端项目

一个使用 **HTML（网页结构） + CSS（网页样式）** 制作的简单静态前端页面，用于展示门店养生项目、服务时长、原价、会员价与项目说明。

这个项目重点不在复杂功能，而在于完成一个 **可直接浏览、可打印、可导出 PDF（便携式文档格式）** 的实际门店价目表页面。

---

## 项目效果

页面采用 A4（标准打印纸张尺寸）竖版布局，通过 CSS（网页样式）控制表格排版、字体、价格高亮、背景图片以及打印效果。

项目同时保留了：

- `养生价表.html`（静态网页源码）
- `1.png`（页面背景素材）
- `养生价目表.pdf`（最终打印版文件）

---

## 使用技术

- HTML（网页结构）
- CSS（网页样式）
- Flexbox（弹性布局）
- Table（表格布局）
- `@page`（打印页面规则）
- A4 Portrait（A4 竖版打印适配）

---

## 实现内容

- 门店服务项目表格展示
- 原价与会员价分栏展示
- 会员价重点高亮
- 背景图片铺满页面
- 多组项目分类排版
- A4 竖版打印适配
- 浏览器直接导出 PDF（便携式文档格式）

## 如何查看

直接打开：

```text
养生/养生价表.html
```

即可在浏览器中查看页面。

如果需要打印，可以在浏览器中使用打印功能，并选择 A4（标准纸张尺寸）竖版布局。

## 项目说明

这是一个偏基础的前端练习与实际应用项目，主要用于熟悉 HTML（网页结构）、CSS（网页样式）、表格排版以及打印页面适配。

相比复杂的前后端项目，这个仓库更侧重展示我从实际需求出发，将简单前端技术落地到真实页面制作中的过程。
